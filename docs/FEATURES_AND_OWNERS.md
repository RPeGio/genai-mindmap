## 建议里程碑和交接

1. **共同基础**：RPeGio 与陈嘉涛共同确定 JSON、接口、代码规范和分支规则（`main` ← `dev` ← `feat/*`，PR 目标 `dev`，中文 Conventional Commits）。先在本人电脑启动当前骨架，验证演示模式生成与读取。
2. **第一轮闭环**：RPeGio 做画布、编辑与保存（R2/R3 已完成），陈嘉涛使用真实模型完成文本生成；RPeGio 与陈嘉涛约定接口、一起用中文样本测试。F01/F04 的后续任务不应因演示模式而跳过。F04 的拖拽调结构、v2 样式与导出排在 W3。
3. **多模态与优化**：陈嘉涛做文档、图片、语音接入及逻辑建议；RPeGio 做样式、布局、预览与建议确认。混合输入和节点来源需 RPeGio 与陈嘉涛共同联调。
4. **知识与协作**：陈嘉涛做知识来源、RAG、知识图谱及代理；RPeGio 做协作、记录与权限。RPeGio 与陈嘉涛共同完成协作中的 AI 建议与翻译。
5. **验收交付**：RPeGio 与陈嘉涛共同补微调研究、PUML、容器部署、自动测试与评估报告。对照所有 F 编号逐条核对，明确已完成与未达标项，不以模块目录替代验收。

共享契约变更必须经 RPeGio 与陈嘉涛共同评审；每项任务单建议包含负责人、输入输出、错误处理、测试样例、演示方式及依赖。第三方模型接口有成本和地区可用性差异，先由 RPeGio 与陈嘉涛确定项目预算和可使用的供应商。
